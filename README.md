# Menu Master

Een simpele, standalone keukenplanner: wijs een weekmenu en brigade toe per dag,
met een print-/PDF-export voor aan de muur.

Alle data (team, gerechten, planning) wordt lokaal in de browser opgeslagen
(`localStorage`) — er is geen server of database bij betrokken.

Live: https://henryh-code.github.io/MenuMaster/

Deze site is met opzet **niet geïndexeerd**: `robots.txt` weert alle crawlers
en de pagina bevat een `noindex, nofollow` meta-tag.
